Antes de guardar el PDF

En el dialogo que se abrira a continuacion, configura exactamente lo siguiente para que el PDF salga en tamano real:

  1. Destino: Guardar como PDF
  2. Orientacion: Horizontal (Landscape)
  3. Tamano de papel: Carta
  4. Margenes: Ninguno
  5. Escala: 100 (no usar "Ajustar")
  6. Cabeceras y pies de pagina: desactivar

Si no seleccionas Margenes = Ninguno, el navegador agrega espacio propio y la imagen se reduce automaticamente.

Instrucciones de uso

  • Paso 1. Tu CSV debe tener una columna con encabezado ETIQUETA. Cada celda con formato numero-nombre, por ejemplo: 64175695-Abad Garcia Mario Isaac.
  • Paso 2. Exporta desde Excel como CSV UTF-8. Si los caracteres especiales (n con tilde, acentos) salen mal, la herramienta reintenta automaticamente con codificacion Windows-1252.
  • Paso 3. Ajusta el tipo y tamano de letra desde los controles del panel. Los cambios se aplican en tiempo real en la vista previa.
  • Paso 4. Haz clic en Exportar PDF. En el dialogo del navegador selecciona destino = Guardar como PDF, escala = 100%, margenes = Ninguno, orientacion = Horizontal.
  • Nota. El PDF generado es un archivo fijo que no puede modificarse desde esta herramienta.
