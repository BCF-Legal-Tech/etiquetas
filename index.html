¿Cómo usar esta herramienta?

Pasos para generar e imprimir etiquetas

  1. Selecciona el modelo de etiqueta desde el menú desplegable según el formato físico que necesites (Janel J-5267, J-5260, etc.).
  2. Prepara tu archivo CSV en Excel con una columna llamada exactamente ETIQUETA, con el formato número-Apellido Nombre. Ejemplo: 10045001-Torres Mendoza Carlos Alberto. Si tienes el número y el nombre en columnas separadas, usa la fórmula de Excel: =CONCATENAR(A2,"-",B2) o su equivalente =A2&"-"&B2 para construir el valor en una sola celda. Exporta desde Excel como CSV UTF-8.
  3. Carga el CSV con el botón Cargar CSV. Si los caracteres especiales (acentos, ñ) salen mal, la herramienta los corregirá automáticamente.
  4. Opcional: Carga un logo en PNG o JPG para que aparezca en el lado izquierdo de cada etiqueta.
  5. Ajusta el tipo y tamaño de letra desde los controles del panel si lo necesitas. Los cambios se aplican en tiempo real.
  6. Exporta el PDF con el botón verde Exportar PDF. En el diálogo de impresión configura: Destino = Guardar como PDF, Escala = 100%, Márgenes = Ninguno, Orientación según el modelo seleccionado.
  7. Limpiar todo reinicia la herramienta para comenzar una nueva sesión sin datos previos.

Antes de guardar el PDF

Configura exactamente lo siguiente en el diálogo de impresión:

  1. Destino: Guardar como PDF
  2. Orientación: Horizontal (Landscape)
  3. Tamaño de papel: Carta
  4. Márgenes: Ninguno
  5. Escala: 100 (no usar "Ajustar")
  6. Cabeceras y pies de página: desactivar

Instrucciones de uso

  • Paso 1. Tu CSV debe tener una columna con encabezado ETIQUETA. Cada celda con formato numero-nombre, por ejemplo: 10045001-Torres Mendoza Carlos Alberto.
  • Paso 2. Exporta desde Excel como CSV UTF-8. Si los caracteres especiales salen mal, la herramienta reintenta con codificacion Windows-1252.
  • Paso 3. Ajusta el tipo y tamaño de letra desde los controles del panel. Los cambios se aplican en tiempo real.
  • Paso 4. Haz clic en Exportar PDF. Selecciona escala = 100%, márgenes = Ninguno, orientación según el modelo seleccionado.
